# 🚀 Felix — Software Engineer & Web Developer Portfolio

A modern, premium, futuristic developer portfolio website for **Felix**, featuring a physics-based interactive lanyard profile card, responsive layout, bento skills grid, featured project showcase, and dynamic dark aesthetic.

## ✨ Key Features

*   **Interactive 3D Physics Profile Card**: Realistic lanyard ID card simulation using `matter-js` with spring physics, drag interaction, and double-sided passport display.
*   **Centralized Data Architecture**: All portfolio information (personal branding, social links, stats, services, skills, achievements, projects) is centrally managed in `src/data/portfolioData.js` for instant updates.
*   **Bento Skills Grid**: Modular categorised skill pills across Web Development, Backend, AI & Automation, Databases, Frontend, and DevOps.
*   **Interactive Projects Carousel**: Smooth scroll-snap showcase with live preview mockups and links.
*   **Futuristic Visual Design**: Connected network particles canvas background, glassmorphism, subtle glowing accents, and responsive layout.

## 🛠️ Tech Stack

*   **Frontend**: React 19, Vite
*   **Physics Engine**: Matter.js
*   **Styling**: Vanilla CSS (CSS Variables, Flexbox, Grid, Glassmorphism)
*   **Data Architecture**: Decoupled JS Configuration

## 🏃‍♂️ Getting Started

1.  **Install dependencies**
    ```bash
    npm install
    ```

2.  **Run development server**
    ```bash
    npm run dev
    ```

3.  **Build for production**
    ```bash
    npm run build
    ```
